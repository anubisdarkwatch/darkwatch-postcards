# Darkwatch Postcards

A Robot 36 SSTV postcard receiver and browser-based USB installer for the Seeed Studio reTerminal Sticky. Connect the Sticky with a USB data cable and open the installer in desktop Chrome or Edge. Installation replaces the existing firmware.

The `docs/` folder contains the static installer, v0.1.3 firmware, source kit, and DW-001 test transmission. To publish from GitHub Pages, choose **Settings → Pages → Deploy from a branch → main → /docs** and save.
